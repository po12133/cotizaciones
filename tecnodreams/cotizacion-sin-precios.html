2Resumen ejecutivo

TecnoDreams 2.0 ya no consiste solo en reemplazar WordPress y WooCommerce por una tienda más rápida. El objetivo principal es un sistema administrativo capaz de gestionar miles de productos de forma eficiente y automatizada: los precios y la disponibilidad siguen calculándose en Excel con las macros actuales y llegan a la plataforma mediante una API REST; las fotografías se organizan por SKU en Amazon S3; y el catálogo se sincroniza con Google Merchant Center mediante un proceso supervisado.

Sobre esa base se construye el catálogo público optimizado, con SEO técnico automatizado, y se migra la información actual desde WooCommerce por etapas, manteniendo el sitio actual operativo hasta validar la nueva plataforma. Junto con esta cotización se entrega un prototipo navegable con un panel que demuestra, con datos simulados, importaciones masivas, gestión de fotografías, precios, SEO y Google Merchant Center.

4Arquitectura técnica

Flujo principal: Excel / Macros → API REST → PostgreSQL → panel administrativo y catálogo público. Las fotografías se suben a S3 y se distribuyen por CloudFront; Google Merchant Center recibe las actualizaciones del catálogo mediante un proceso independiente y supervisado.

6Módulos clave en detalle

Excel y API RESTExcel sigue siendo la fuente operativa de los precios y la disponibilidad calculados por sus macros. Las macros envían las filas a la API con un token propio; el backend valida, actualiza por SKU y registra cada cambio. La compatibilidad con las macros existentes debe validarse antes de comprometer una migración sin modificaciones.
Fotografías en Amazon S3Cada producto tiene su carpeta productos/SKU/. S1.webp es la imagen principal; S2.webp, S3.webp… forman la galería; SZ.webp es la imagen para Google Merchant Center (sin ella, el producto queda pendiente). Al reemplazar una imagen se genera una URL versionada. Cargas seguras con URLs firmadas, permisos restringidos y distribución por CloudFront; sin credenciales de AWS en el navegador.
SEO técnico automatizadoSEO automático por producto, metadescripciones, URLs amigables, canonical, sitemap XML, robots.txt, datos estructurados Product, Offer y BreadcrumbList, renderizado compatible con motores de búsqueda y conservación de URLs existentes con redirecciones 301.
Google Merchant CenterIntegración mediante Merchant API o feed automático, según la evaluación técnica. Un proceso independiente valida (SKU, precio, SZ.webp, marca) y envía los cambios; los estados enviado, procesado, aprobado y rechazado se muestran por separado, y los dos últimos dependen siempre de la respuesta de Google.

7Migración desde WooCommerce

Se migran productos, SKU, categorías, marcas, atributos, variaciones, precios, descripciones, fotografías, datos SEO existentes y URLs actuales, generando las redirecciones 301 correspondientes. WordPress se mantiene operativo hasta validar la nueva plataforma.

11Condiciones y exclusiones

La propuesta incluye el desarrollo de los módulos indicados dentro de un alcance estándar y previamente definido. No incluye:

  • Hosting y servidores.
  • Consumo de Amazon S3.
  • Consumo de CDN.
  • Dominio.
  • Suscripciones de terceros.
  • Comisiones de pasarelas de pago.
  • Integraciones extraordinarias con ERP.
  • Facturación fiscal especializada.
  • Funcionalidades adicionales no contempladas.
La compatibilidad con las macros existentes debe validarse antes de comprometer una migración sin modificaciones. Si la validación muestra cambios mayores a los previstos, se informarán antes de ejecutarlos.
